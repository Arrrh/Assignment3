# Getting and Cleaning Data Course Project

## Overview
This project processes **Samsung Galaxy S smartphone accelerometer data** to create a tidy dataset.

## Steps
1. Merged training & test data.
2. Extracted mean & standard deviation measurements.
3. Applied descriptive activity names.
4. Cleaned variable names.
5. Created a final tidy dataset with averages.

See `CodeBook.md` for details on variables.
